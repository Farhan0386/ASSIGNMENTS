# Machine Learning with Python — Assignment Requirements

- **Format:** `.py` files only (one separate file per topic)
- **Total Files:** 9 files across Sections A, B, C, and D
- **Goal:** Every script must run cleanly from start to finish without errors, using self-contained/synthetic/built-in data so no external missing file causes a crash.

## Section A: Python Libraries
1. `numpy_code.py` — NumPy: arrays, indexing, slicing, broadcasting, statistics, and basic linear algebra.
2. `pandas_code.py` — Pandas: DataFrames, cleaning missing values, filtering, groupby, merge, and reading/writing CSV.
3. `seaborn_code.py` — Seaborn: statistical plots including histogram, box, violin, scatter, heatmap, and pairplot.
4. `matplotlib_code.py` — Matplotlib: line, bar, scatter, histogram, pie, and subplot charts with titles, labels, and legends.

## Section B: Regression Models
1. `house_price_linear_regression.py` — House Price Prediction: Linear Regression to predict price from area, bedrooms, age, and distance. Report MAE, RMSE, and R2.
2. `sentiment_logistic_regression.py` — Sentiment Analysis: Logistic Regression on text reviews to classify positive or negative. Report accuracy and confusion matrix.
3. `iris_softmax_regression.py` — Iris Species Prediction: Softmax Regression on the Iris dataset to predict the species (3 classes). Report accuracy.

## Section C: K-NN Classification
1. `knn_students_classification.py` — K-NN on Student Data: Use students' CGPA and IQ to classify them with K-Nearest Neighbours. Scale the data, choose a suitable K, and report accuracy.

## Section D: K-Means Clustering
1. `kmeans_student_clustering.py` — Student Clustering: Group students by CGPA and IQ with K-Means. Choose K using the elbow method and describe each cluster.
