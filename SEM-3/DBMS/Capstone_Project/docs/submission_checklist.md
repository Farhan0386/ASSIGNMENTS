# Submission Checklist

## Phase 1 — 20 marks
- [ ] `ERD.svg` and editable `ERD.mmd`
- [ ] Data dictionary
- [ ] 1NF, 2NF and 3NF explanation
- [ ] Final schema DDL
- [ ] Successful schema creation evidence

## Phase 2 — 20 marks
- [ ] Annual tax and monthly salary functions
- [ ] Monthly payroll stored procedure
- [ ] Leave, attendance, salary and tax-band triggers
- [ ] 12 employees and 3 months of attendance sample data
- [ ] Function/procedure/trigger execution evidence

## Phase 3 — 20 marks
- [ ] Monthly attendance summary
- [ ] Employee salary slip report
- [ ] Late-marks report
- [ ] Index definitions
- [ ] Actual before/after query plans and explanation

## Phase 4 — 20 marks
- [ ] HR/Admin vs Employee role checks
- [ ] RLS evidence for own-record scope
- [ ] Employee role is read-only for own records (including leave)
- [ ] Employee role denied from calling payroll procedure
- [ ] CSRF token rejection test
- [ ] Transaction COMMIT evidence
- [ ] Transaction ROLLBACK evidence
- [ ] Valid, invalid and boundary test outputs

## Phase 5 — 20 marks
- [ ] Integrated Flask application
- [ ] HR/Admin can create/edit employees and activate/deactivate access
- [ ] HR/Admin and Employee dashboards
- [ ] README and setup instructions
- [ ] Source code and SQL scripts
- [ ] Application screenshots/output traces
- [ ] Short project report
- [ ] Presentation and live demo
