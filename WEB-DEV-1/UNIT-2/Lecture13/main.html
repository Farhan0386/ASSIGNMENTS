CSS Positioning & Basic Layout - Summary Notes

Introduction

CSS positioning helps control where elements appear on a web page. By default, elements stack top to bottom, but positioning allows movement, layering, and flexible layouts.

Types of CSS Positioning

  • Static – Default, elements follow normal flow.
  • Relative – Element stays in flow but can be shifted.
  • Absolute – Removed from flow, positioned relative to nearest positioned ancestor.
  • Fixed – Stays fixed relative to viewport.
  • Sticky – Acts like relative until a scroll threshold, then sticks.
